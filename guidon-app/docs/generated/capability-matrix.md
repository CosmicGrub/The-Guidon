## Degradation when absent

- **indexeddb** (required): Nothing persists: grades, board dates and settings are lost on reload. The app cannot ship without it.
- **storagePersist**: The browser may evict IndexedDB after ~7 days idle (iOS); Diagnostics' Storage durability check reports it, Share & Install mitigates it.
- **share**: Share buttons fall back to copy-to-clipboard or a plain download.
- **download** (required): Backups, PDFs and self-heal logs cannot be saved as files (Android/iOS route through Filesystem+Share instead, see util.download).
- **print** (required): Readiness summary and DA 4856 flatten-and-print are unavailable (Android uses the native print path, see test-print-native).
- **haptics**: Board-drill grade feedback is visual only.
- **notifications**: Reminder alerts only show inside the app; nothing fires while it is closed.
- **biometric**: Personal Account biometric lock is not offered (Settings hides the toggle).
- **fullscreen**: Board-drill theater mode uses a fixed overlay instead of true fullscreen (iPhone WKWebView).
- **broadcastChannel**: Two windows of the same origin do not sync (src/xwin.js is inert); each window still works alone.
- **webCrypto**: Unused today; a future room key exchange (P3/P4) needs it. Absent on plain http:// origins.
- **webSocket**: Study groups (LAN rooms, P3/P4) cannot connect; everything else is offline by design. The API existing is not a LAN room: page JS on any https:// origin (a hosted web or pwa page, android's https://localhost WebView) opening ws:// to a LAN IP is blocked as mixed content, so rooms from those origins need a native socket (the Capacitor side) or a wss:// endpoint; the plain http:// guest page and http://tauri.localhost are not blocked.
- **rtcDataChannel**: Peer-to-peer rooms (P4 option) unavailable; a LAN WebSocket room still works.
- **getUserMedia**: Unused today; recorded so a future camera/mic feature has a measured floor.
- **wakeLock**: The screen may dim during a long drill; nothing else changes.
- **colorMix** (required): The five --ink-* text tokens (src/index.html) resolve to nothing: accent-coloured text renders in the build-generated static fallback colour. Engine floor Q11: Chromium 111 / WebKit 16.2 / Gecko 113 (window.GUIDON_ENGINE_FLOOR, from tools/engine-floor.json).
- **containerQueries**: Unused today (0 container-type rules); recorded for the engine floor.
- **hasSelector**: Unused today (0 :has() rules); recorded for the engine floor.
- **dialog**: G.modal draws its own overlay and never depends on <dialog>; recorded for the engine floor.
- **viewTransitions**: Route changes cut instead of cross-fading; unused today.
- **speechSynthesis**: Unused today; recorded so a read-aloud drill option has a measured floor.
- **serviceWorker**: No offline precache for the hosted build; native shells never register one (assets ship locally), the standalone file needs none.
- **secureContext**: Web Crypto, storage persistence and share are gated on it; a plain http:// host loses them (localhost and file:// count as secure).
- **origin**: Recorded value, not a capability: "null" is the file:// standalone origin, so same-origin features (BroadcastChannel sync) are off there.
